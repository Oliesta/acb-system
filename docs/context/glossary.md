# Glossary

| Term | Meaning |
|------|---------|
| **Anchor** | Writing a single hash that summarises a batch of records to a public blockchain, so anyone can later prove the batch was not changed. See [ADR-002](../architecture/decision-records/ADR-002-public-chain-anchoring.md). |
| **Approver** | A named official with authority to approve a payment release for a given public body. |
| **Contract** | An awarded agreement between a public body and a supplier, with a value and one or more milestones. |
| **CSD** | National Treasury Central Supplier Database. Holds supplier registration, tax compliance and bank verification status. |
| **Evidence** | Any item submitted to support a milestone claim: photos, inspection reports, delivery notes, invoices. |
| **Glass Pipe** | The public portal that shows contracts, milestones, evidence summaries and payments. |
| **Inspector** | A person assigned to verify a milestone on site. Can be a professional (engineer, quantity surveyor) or a trained watchdog. |
| **Ledger** | The append-only record of all events in the system. Stored off-chain, anchored on-chain. |
| **Milestone** | A defined, checkable unit of delivery inside a contract, with a value and acceptance criteria. |
| **Milestone claim** | A supplier's statement that a milestone is complete, with an invoice. |
| **Payment release gate** | The rule check that decides whether a milestone payment may be authorised. It sends an authorisation to the public body's financial system. It never holds or moves money. |
| **Personal information** | As defined in POPIA. Includes names, ID numbers, contact details, bank details and images of identifiable people. |
| **Public body** | A national or provincial department, municipality, public entity or state-owned company. |
| **Supplier** | The contractor or vendor awarded a contract. |
| **Variation** | An approved change to a contract's scope, value or milestones after award. |
| **Verification decision** | The recorded outcome of a milestone check: Accepted, Rejected or Needs more evidence. |
| **Watchdog** | A trained community member who submits site observations. Watchdog evidence supports, but never alone decides, a verification. |
