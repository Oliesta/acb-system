# Security Policy

The ACB System is in the concept stage and has no deployed code yet. Design weaknesses are still very welcome.

## Reporting a vulnerability

- Email **oliestao@gmail.com** with the subject line `ACB security`.
- Do **not** open a public issue for a vulnerability.
- Include what you found, how to reproduce it, and its likely impact.
- You will get a reply within 7 days.

## Design flaws

Flaws in the design, such as a way to collude around a rule, MAY be raised as public issues, because the design is already public. Please reference the threat ID or Rule ID from the [threat model](docs/architecture/security.md).
